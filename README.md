# LaTeX Studio

面向 Windows 的本地 LaTeX 写作工具：源码编辑、PDF 预览、宏包管理与可审阅的 AI 修改，在同一个工作区完成。

当前版本：**1.6.4** · Windows 10 / 11 x64 · 公开仓库

## 安装

从 [安装包目录](distribution/) 下载 `LaTeX-Studio-1.6.4-win64-Setup.exe`。使用旁边的 `SHA256SUMS.txt` 核对文件，再双击安装。默认位置为 `D:\LaTeXStudio`，首次安装和升级均显示安装位置选择页。更换位置不会自动迁移原有项目和设置；原位置升级保留用户数据。

安装包包含独立 Python、Tectonic 编译器、PDF 渲染组件、离线前端与基础 TeX 资源；无需另装 Python、Node.js 或 LaTeX。界面不依赖公共 CDN。未缓存的宏包需要联网下载。

程序尚未购买 Windows 代码签名证书，安装程序的发布者可能显示为“未知”。SHA256 用来核对下载文件，不等同于代码签名。

## Chat 与 Agent

AI 助手默认打开对话区。Chat 只讨论；Agent 可读取项目、诊断编译错误、检查引用和术语、修改多个源码文件，在临时副本中编译并检查 PDF，通过后由你确认应用。左侧选择源码范围或 PDF 页次后，点击“关联所选内容”；也可添加文本、PDF、DOCX 或图片附件。附件按需读取，单个上限 8 MB，每轮最多关联 8 个。原有排版与全文审核位于“审阅工具”。

会话保留历史与 token 用量。Agent 采用内部步骤和用量预算，页面无需手动设置次数；遇到需要补充的信息、重复无进展或预算用尽会暂停，保留候选并支持继续。按需读文件、分页、压缩图片、复用未变化的编译结果与本地整理旧工具信息，减少重复发送。面板宽度与输入区高度可拖动调整，也可展开对话或返回文档分栏。工作记录显示动作说明、文件/页次和结果；次数与用量收进对话信息。支持停止、效果预览、源码差异与撤销。

## 术语与数据审阅

在编辑器的“文档工具 → 术语表”勾选已有术语，点击“AI 检索所选术语”；也可点击“AI 提取全文术语”建立全文术语结果。结果页勾选同义写法、核对“统一为”后，可直接“统一替换并编译”，也可先预览，支持撤销；全称缩写和相关概念保持独立。审核过的条目可去重导入术语表，不覆盖已有译词。公式、引用、代码和定义说明受保护；AI 判断仍需审阅。全文提取一次发送可读正文，支持 18 万字符以内的项目。

数据检查用于核对论文指标与实验导出的 CSV / JSON。Python 常量只作候选，需要确认属于相同实验；没有来源表示尚未核对，不表示有错。可直接导入实验数据，来源选择按项目保存。

“改动关联”展示选区、图表标签、引用位置和已编译 PDF 页面，便于改动后逐项复核；它不预测所有分页变化。

## 主要功能

- Monaco 源码编辑、项目搜索、上下文、章节大纲。自动保存编辑和 AI 应用/撤销前后版本，保留最近 30 个不同状态；可手动保存、逐项对照、恢复到编辑区。
- 编辑器 AI 保留最近 20 次任务，清空面板后仍可从历史查看。
- PDF.js 预览，源码与 PDF 双向定位；使用显眼的“定位 PDF → / ← 定位源码”按钮，或双击 PDF。标签、文献和引用优先定位编译后的具体条目；普通正文定位到源码行附近，并标注近似定位。
- 文档工具中的引用检查可展开文件、标签、交叉引用和文献，查看完整条目、定义与使用位置。
- 改动影响地图：查看当前选区或文件关联的页码、标签、引用、文件和资源；页码依赖最新编译，静态关联不保证涵盖重排、动态宏等全部影响。
- 数据一致性检查：本地核对正文、表格与 CSV / JSON / Python 静态数值，支持百分比、单位换算、舍入及手动选择数据依据。存在多个不同依据时提示待核对；不会执行 Python，也不自动改写论文。
- 多项目管理、导入、共享宏包搜索、下载、验证和缓存管理。
- PDF 连续阅读与逐页勾选，支持 Shift 连选、页码范围与全选页面，最多 80 页。
- 多页连续对照，红色标记修改前、绿色标记候选结果；可定位具体建议、拖动分栏并调整对照宽度。
- PDF 页面或源码范围的排版、纠错、润色和翻译；多页审阅共享章节提纲、相邻正文与前页结论。
- 全文审核先综合源码和全页提纲建立统一意见，再逐页检查内容与版式。发送前确认范围与请求数；全文最多 80 页、上下文 60000 字符。
- AI 默认保留未请求改动的内容；用户明确要求时可删除引用、参考文献、章节或重写内容，不按删减比例阻止。确认前必须生成可编译、可渲染的候选预览，支持差异查看和撤销。
- AI 修改遵循“生成修改 → 自动编译预览 → 确认应用”，可查看差异和撤销；预览失败时保留原文件。
- 编辑器内的 AI 修复面板与编译验证，支持清空对话；底部面板高度、输入栏和前后预览分栏均可拖动，支持键盘调整、双击还原并记忆尺寸。
- 文档工具窗口可移动、缩放和记忆位置；定位后保持打开，支持收起与恢复。源码定位高亮自动消退。
- 功能页右上角提供圆形“!”说明入口；白底深色文字，少量蓝绿点缀。

全文审核先建立全局意见，再逐页检查。无法可靠映射源码的页面仅提供建议；所有修改仍需临时编译、预览和确认。

## 文件与隐私

```text
安装目录/
  app/       程序
  python/    独立运行环境
  runtime/   编译器
  projects/  文档项目（可在设置中迁移）
  cache/     宏包与临时文件（可在设置中迁移）
  data/      本机设置、加密凭据与历史记录
```

AI 服务默认需要用户自行配置。密钥由 Windows DPAPI 加密，绑定当前 Windows 账户；只在向用户选择的服务发出请求时使用。打开 AI 页面、选择任务和查看修改不会自动调用模型。远程 AI 请求会发送用户选择的文本或页面及相关上下文，请按文档保密要求选择服务。

**仓库、安装包不包含个人 API 密钥、SSH 私钥、会话令牌、实验报告、AI 对话或本地修改记录。** 更新和重新安装保留 `data/`、项目和缓存。卸载也保留这些用户目录。

## 版本与更新

打开“设置 → 版本与更新”。默认手动检查，可开启启动时检查。公开仓库可直接检查更新，无需 GitHub 凭据。若未来改为私有，可配置仅限本仓库 **Contents: Read-only** 的 GitHub 凭据；它与 AI 密钥分开加密保存。不要把凭据写入源码或发到 issue / 聊天。

更新清单位于 [`updates/latest.json`](updates/latest.json)。检查时固定 GitHub 提交，下载该提交中的安装包，并验证版本、文件名、长度和 SHA256。校验失败不允许运行；安装前再次核对文件。安装始终由用户点击，不会静默替换文档。

当前通过仓库的 `distribution/` 提供安装包，避免创建 Releases 还需另一组写入凭据。后续版本可迁移为 GitHub Releases；源码版本标签仍使用 `v1.0.1` 形式。

## 开发

安装 Python 3.10 以上，执行 `python -m pip install -r requirements.txt`，准备 `vendor/` 中的离线前端组件。编译器与资源按 Tectonic 的许可获取。用 `bootstrap_install.py --home <安装根目录>` 写入本机路径后，以 `app/launch.ps1` 启动。

`version.json` 是版本信息的唯一来源：`version` 使用语义版本，`build` 标识内部兼容性，`channel` 当前为 `stable`。

下次发布先运行 `python tools/set_version.py <新版本> --build <studio-N>`，补充更新记录，再构建和测试。构建脚本会写出 SHA256 清单和对应版本清单；提交后创建同名 `v<新版本>` 标签并推送。

构建入口见 [`tools/build_release.py`](tools/build_release.py)，安装脚本为 [`installer/LaTeXStudio.iss`](installer/LaTeXStudio.iss)。发布前运行 `python tools/audit_release.py .`，并实际测试独立安装与升级保留数据。
